# Задачи по доработке игры «Виселица»

Игра уже работает, но её можно улучшить.
Задачи идут по возрастанию сложности. Старайся не ломать то, что уже работает.

## Задача 1. Исправить вывод при победе 🟢

**Проблема:** в конце игры всегда печатается `"You lost, word was: ..."`, даже если игрок угадал слово.

**Что сделать:**
- Добавить флаг (например, `bool won = false;`) или проверку после цикла.
- Если игрок выиграл — выводить поздравление, и НЕ выводить сообщение о проигрыше.

**Готово, когда:**
- При победе выводится только `"You won!"`.
- При проигрыше выводится `"You lost, word was: ..."`.

## Задача 2. Показывать состояние перед вводом 🟢

**Что сделать:**
- Перед `std::cin >> user_choice;` выводить текущее состояние игры в формате:
  ```
  Word: a___a   Attempts: 6
  > 
  ```

**Готово, когда:**
- Игрок видит открытые буквы, прочерки на месте закрытых и число оставшихся попыток.
- После каждого хода экран не «замусорен» — состояние читается.

## Задача 3. Проверять корректность ввода 🟢

**Что сделать:**
- Если игрок ввёл не букву латинского алфавита (`'a'`–`'z'` или `'A'`–`'Z'`), не тратить попытку.
- Выводить сообщение: `"Please enter a letter a-z."` и просить ввод заново.
- Приводить ввод к нижнему регистру (`std::tolower`), чтобы `'A'` и `'a'` считались одной буквой.

**Готово, когда:**
- Ввод `'1'`, `'!'`, `' '` не уменьшает `attempts`.
- `'A'` открывает букву `'a'`.

## Задача 4. Не тратить попытку за повторный ввод 🟡

**Что сделать:**
- Хранить уже введённые буквы (например, в `std::string used_letters;`).
- Если игрок вводит букву, которую уже вводил — не тратить попытку.
- Выводить: `"You already tried 'x'."`

**Готово, когда:**
- Повторный ввод `'a'` не меняет `attempts` и не портит состояние игры.

## Задача 5. Вынести логику в функции 🟡

**Что сделать:**
Разбить `main()` на функции:
```cpp
void print_state(const std::string& play, int attempts);
bool is_valid_letter(char c);
bool process_guess(char guess, const std::string& secret, std::string& play);
```
- `process_guess` возвращает `true`, если буква есть в слове, и открывает ВСЕ её вхождения.
- Строки передаются по константной ссылке (`const std::string&`), если их не надо менять.

**Готово, когда:**
- `main()` стал коротким и читается как алгоритм.
- Программа работает так же, как до рефакторинга.

## Задача 6. Список слов и случайный выбор 🟡

**Что сделать:**
- Заменить одно слово на `std::vector<std::string>` из 5+ слов.
- Выбирать случайное слово через `std::mt19937` + `std::uniform_int_distribution`.
- **Не использовать** `rand()` и `srand()`.

**Готово, когда:**
- При каждом запуске слово выбирается случайно.
- Слово выбирается из вектора, а не хардкодится.

## Задача 8. Подсказка за попытку 🟠

**Что сделать:**

**Готово, когда:**
- `?` открывает ровно одну букву.
- За использование подсказки списывается 2 попытки.

## Задача 11 (со звёздочкой). Юнит-тесты без фреймворка 🔴

**Что сделать:**
- Вынести `process_guess` в отдельный `.cpp` + `.h`.
- Написать `assert`-проверки в отдельном файле:
```cpp

assert(process_guess('a', "aboba", play) == true);
assert(play == "a___a");
assert(process_guess('x', "aboba", play) == false);
assert(play == "a___a");
```
- Собрать тесты отдельной целью и убедиться, что все `assert` проходят.

**Готово, когда:**
- Тесты компилируются и проходят без падений.
- Намеренно сломанный `process_guess` приводит к падению `assert`.
